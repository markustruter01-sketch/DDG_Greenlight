# Greenlight provenance

Imported from public repository `pierretruter07-sudo/gods-eye-view`, branch
`export/crosscheck-standalone`. Original attribution and catalogue licences are
preserved in NOTICE.md and individual catalogues. The original assessment,
signals, intake, scoring and remediation planner are reused, not replaced.

Greenlight removes the optional AI rater completely. Assessments ignore any
AI rating input; unavailable evidence remains unrated. Detecting AI libraries
in the assessed repository is a deterministic code signal, not AI checking.

Classification patterns live in classification-rules.json and only suggest a
business-impact classification for a human to confirm.
